# Shadowing Lab

혼자 영어 섀도잉을 반복하다가, 매번 녹음하고 비교하고 피드백을 정리하는 과정이 지쳐서 만든 개인 학습 프로젝트입니다.  
한 문장을 듣고 따라 읽은 뒤, 발음·강세·리듬·연결을 확인하고 다시 도전하면서 변화를 직접 비교할 수 있도록 만드는 것이 목표입니다.

## Current Status

- Public beta
- First created: 2026-09-15
- Current version: v1.4.2

## Main Features

- 레벨별 영어 섀도잉 문장 제공
- 예문과 자연스러운 한국어 번역 표시
- 예문 음성 듣기 및 속도 조절
- 브라우저 마이크 녹음
- 발음 평가 및 세부 피드백
- 최대 3회 재녹음 및 첫 시도 대비 변화 확인
- 시도별 녹음 재생 및 음성 파일 저장
- 이전 시도 피드백 다시 보기

## Tech Stack

- HTML
- CSS
- JavaScript
- Python

외부 음성·평가 서비스 및 내부 평가 로직의 상세 구성은 공개 문서에 별도로 기재하지 않습니다.
